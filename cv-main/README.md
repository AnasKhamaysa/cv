# Anas Khamaysa — Personal Portfolio

Responsive, English-language portfolio built using semantic HTML, CSS and vanilla JavaScript. No build step required.

## Deploy

Upload the contents of this folder (not the enclosing folder) to the root of the `AnasKhamaysa.github.io/cv` GitHub Pages project. If the repository uses a `main` branch `/docs` source, move the contents to the configured publishing folder.

## Files

- `index.html`, `style.css`, `script.js`: website source files
- `ANAS_KHAMAYSA_CV_EN.pdf`: English CV (print/download)
- Certificate and research PDFs: supporting documents linked from the website
- `anas_ico.ico`: favicon
